Virtual DOM 실험실

실제 영역의 HTML을 Virtual DOM으로 읽어 미리보기를 만듭니다. 편집 내용을 비교해 바뀐 부분만 실제 영역에 반영합니다.

  • 동작 지금 실제로 동작하는 기능
  • 준비 중 자리만 잡아 둔 기능 · 조작할 수 없음
이력 0 / 0 최대 10개 보관

초기 콘텐츠를 불러오는 중입니다.

Patch를 계산하는 중입니다…

성공 후 편집기 HTML의 표기가 달라질 수 있습니다.

01

실제 영역

Patch 결과

Patch가 성공하거나 이력을 이동할 때 바뀌는 영역입니다. 입력값은 미리보기에서 변경합니다.

02

테스트 영역

미리보기 · 편집기
수동 갱신

Tab은 두 칸 들여쓰기, Shift+Tab은 내어쓰기입니다. 편집기 밖으로 이동하려면 Esc를 누른 다음 Tab 또는 Shift+Tab을 누르세요. HTML을 편집한 뒤 미리보기 갱신을 눌러 주세요. 지원하는 태그·속성은 아래 안내를 참고하세요.

미리보기를 복원하지 못했습니다. 보관된 입력값이 있으며 미리보기를 갱신해 주세요.

편집 내용이 반영되지 않았습니다. 미리보기를 갱신해 주세요.

미리보기 초기 로드

미리보기의 입력값은 바꿀 수 있지만, 실제 영역이나 이력에 반영되지는 않습니다.

03

비교 결과

· 스페이스, → 탭, ↵ 줄바꿈

현재 선택된 이력이 처음 저장될 때의 비교 결과를 보여 줍니다.

결과 HTML 비교

Virtual DOM Diff

HTML 글자 비교와 Virtual DOM Diff는 기준이 서로 다른 별개의 결과이므로 건수가 달라도 오류가 아닙니다. HTML 색상만으로 실제 DOM에 반영된 작업을 판단하지 않습니다.

04

Virtual DOM 살펴보기

동작

현재 이력에 저장된 트리입니다. 대괄호는 공백 텍스트를 포함한 childNodes 기준 경로입니다.

트리를 불러오는 중입니다.

현재 편집을 반영하지 않은 비교입니다.

05원본 HTML 비교 동작

Patch를 누른 시점의 편집 기준 HTML과 편집기에 작성한 HTML을 글자 단위로 비교합니다. 브라우저 직렬화로 바뀐 따옴표·들여쓰기와 달리 사용자가 직접 바꾼 표기를 확인하는 곳입니다.

06

안내

Patch 흐름 동작

  1. 편집기 HTML 검사
  2. 필요하면 미리보기 갱신
  3. 새 트리 생성 · 이전 트리와 비교
  4. 변경 건수 확인 창
  5. 바뀐 부분만 실제 영역에 반영
  6. 성공하면 새 이력 저장

변경이 없으면 이력을 만들지 않고 알려 줍니다. 적용에 실패하면 이전 상태로 복구를 시도합니다.

변경 이력

성공한 Patch는 이력에 보관됩니다.

  • 초기 상태를 포함해 최근 10개까지 보관합니다.
  • 과거 이력에서 새로 Patch하면 그 뒤의 이력을 지웁니다.
  • 적용하지 않은 편집이 있으면 이동 전에 확인합니다.
  • 임시 저장본이 있으면 같은 탭 새로고침 뒤 복원할 수 있습니다.

지원하는 HTML

div section p span strong em h1~h6 ul ol li input textarea select option button label

공통 속성 id class title style. input은 text·checkbox·radio만 지원합니다. 스크립트·이벤트 속성·주석·<style>은 지원하지 않습니다.

style 속성

허용 목록에 있는 선언만 사용할 수 있습니다: color, background-color(색 이름·#16진), font-size·width·height·margin·padding(px 하나), font-weight, text-align, display, white-space.
