실제 영역의 HTML을 Virtual DOM으로 읽어 테스트 영역 미리보기를 만듭니다. 편집 내용을 비교해 바뀐 부분만 실제 영역에 반영하는 단계는 순서대로 준비하고 있습니다.

  • 동작 지금 실제로 동작하는 기능
  • 준비 중 자리만 잡아 둔 기능 · 조작할 수 없음
이력 0 / 0 최대 10개 보관 · 준비 중

  • 변경 구간마다 앞뒤 3줄의 문맥과 이전·새 줄 번호
  • 변경 구간 2개, 이전 2줄 → 이후 1줄처럼 구간 단위 요약

Virtual DOM Diff

준비 중

두 Virtual DOM을 같은 위치끼리 비교해 찾은 변경과 폼 상태 변경을 따로 셉니다. 변경이 없으면 변경 없음을 표시합니다.

  • 요소 추가·삭제·교체, 텍스트·속성·style 변경, 입력창의 현재 값·선택 변경
  • section 안의 두 번째 p 요소 같은 위치 설명과 childNodes 경로

HTML 글자 비교와 Virtual DOM Diff는 기준이 서로 다른 별개의 결과이므로 건수가 달라도 오류가 아닙니다. HTML 색상만으로 실제 DOM에 반영된 작업을 판단하지 않습니다.

05원본 HTML 비교 준비 중

Patch를 누른 시점의 편집 기준 HTML과 편집기에 작성한 HTML을 글자 단위로 비교합니다. 브라우저 직렬화로 바뀐 따옴표·들여쓰기와 달리 사용자가 직접 바꾼 표기를 확인하는 곳입니다.

아직 구현되지 않았습니다. 검사에 오류가 있어도 비교는 표시하되 적용되지 않은 편집임을 함께 알릴 예정입니다.

안내

Patch 흐름 준비 중

  1. 편집기 HTML 검사
  2. 필요하면 미리보기 갱신
  3. 새 트리 생성 · 이전 트리와 비교
  4. 변경 건수 확인 창
  5. 바뀐 부분만 실제 영역에 반영
  6. 성공하면 새 이력 저장

변경이 없으면 이력을 만들지 않고 알려 줍니다. 적용에 실패하면 이전 상태로 복구를 시도합니다.

지원하는 HTML

div section p span strong em h1~h6 ul ol li input textarea select option button label

style 속성

허용 목록에 있는 선언만 사용할 수 있습니다: color, background-color(색 이름·#16진), font-size·width·height·margin·padding(px 하나), font-weight, text-align, display, white-space.
